HOW TO UPDATE THE BCC LIST FOR KINETIC O&P CONTACT/INTAKE FORMS
================================================================

Ask Claude to do the following:

1. Open the file: C:\Users\ml81062\source\kineticop\worker\wrangler.toml

2. Find the line that starts with: BCC_LIST =

3. Edit the comma-separated list of email addresses between the quotes.
   - Regular emails look like: REDACTED_EMAIL
   - Text message notifications look like: REDACTED_SMS

   Carrier email-to-text addresses:
   - Verizon:  number@vtext.com
   - AT&T:     number@txt.att.net
   - T-Mobile: number@tmomail.net
   - Sprint:   number@messaging.sprintpcs.com

4. After editing, deploy the worker by running this command:
   npx wrangler deploy --config "C:\Users\ml81062\source\kineticop\worker\wrangler.toml"

5. Then commit and push:
   cd C:\Users\ml81062\source\kineticop
   git add worker/wrangler.toml
   git commit -m "Update BCC list"
   git push
