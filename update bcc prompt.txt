HOW TO UPDATE THE BCC LIST FOR KINETIC O&P CONTACT/INTAKE FORMS
================================================================

The BCC list is stored as a Cloudflare secret (not in code).
To update it, run a command with the full updated list.

STEP 1 - Update the secret (replace the list with your full updated list):
cd C:\Users\ml81062\source\kineticop\worker
echo "email1, email2, phonenumber@carrier" | npx wrangler secret put BCC_LIST

STEP 2 - Also update the local .dev.vars file for testing:
Edit C:\Users\ml81062\source\kineticop\worker\.dev.vars
and update the BCC_LIST line to match.

Carrier email-to-text addresses:
- Verizon:  number@vtext.com
- AT&T:     number@txt.att.net
- T-Mobile: number@tmomail.net
- Sprint:   number@messaging.sprintpcs.com
